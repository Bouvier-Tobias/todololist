# 🚀 Mon Projet Git

Bonjour ! Ce projet est un exemple simple pour apprendre à utiliser Git et centraliser mon code.

## 🛠️ Ce que j'ai appris
* **Créer des branches** pour travailler en sécurité.
* **Indexer et commiter** mes modifications locales.
* **Pousser le code** sur le dépôt distant (`origin/main`).

## 📌 Statut actuel
Le code est **à jour** et synchronisé avec le dépôt distant !
